# Publishing articles

This is a static site, so each article is a standalone HTML page and can be published without a CMS or build step.

1. Copy one of the article pages in this folder and give the copy a short, lowercase filename ending in `.html`.
2. Replace its title, description, heading, and article content. Keep the shared stylesheet and navigation links so assets resolve from this folder.
3. Add a matching article card to `../research-insights.html` with a link to `articles/your-file.html`.
4. Check the new link and page locally, then publish the change through the repository's normal deployment process.

Keep article claims factual, add a publication date and author only when confirmed, and use a concise summary that accurately describes the page.
